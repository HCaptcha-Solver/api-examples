# Contributing

Use an issue for a reproducible problem with these examples. Include your Python/Node version, the command with secrets removed, the error code and the expected behavior. Replace real captures with synthetic images when possible.

Never attach API keys, CAPTCHA tokens, cookies, account details or customer screenshots to a public issue. Account and billing questions belong at contact@hcaptchasolver.org.

Before opening a pull request, run both offline test suites from the README. Keep example clients independent of the service's internal implementation. Add tests for changes to request IDs, polling or response handling; tests must not contact the paid API.
